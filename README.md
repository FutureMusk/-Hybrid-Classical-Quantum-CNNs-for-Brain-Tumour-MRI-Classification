# -Hybrid-Classical-Quantum-CNNs-for-Brain-Tumour-MRI-Classification
Hybrid Classical–Quantum CNN for brain tumour MRI classification. Combines EfficientNet-B0 with a parameterised quantum circuit (PQC), tested across four controlled conditions with patient-level data splits, repeated cross-validation, and formal equivalence testing. Central finding: the quantum layer is trainable but inert.
